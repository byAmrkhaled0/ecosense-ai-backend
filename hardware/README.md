# Ecosense AI Hardware

This folder contains the hardware implementation files for the Ecosense AI project.

## Contents

- arduino-code/final.ino: Arduino/ESP32 code used for reading sensor values and sending plant environment data.

## Main Components

- ESP32 / ESP32-CAM
- Soil Moisture Sensor
- DHT Sensor
- Light Sensor
- Soil Temperature Sensor

## Purpose

The hardware part collects environmental readings from the plant and sends them to the backend for analysis.
